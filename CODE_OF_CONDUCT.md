# Code of Conduct

This is a library for curious people with different backgrounds, abilities, tools and experience. Treat contributors and original creators with patience and respect.

We welcome questions, corrections and disagreement about evidence. Explain what you observed, assume good intent, credit other people's work and make room for beginners. Do not pressure anyone to finish a project, buy equipment or share personal information.

Harassment, discrimination, threats, sexualized conduct, doxxing, plagiarism, spam and undisclosed promotional submissions are not welcome. Do not encourage unsafe work or unauthorized security testing.

Maintainers may edit or remove contributions, close discussions, warn contributors or restrict participation according to the severity and pattern of conduct. They should explain decisions proportionately, protect reporters' privacy and apply these standards consistently.

Report ordinary problems through an issue. For a concern containing private information, use a private contact route published by the repository owner on their GitHub profile; do not post personal details publicly. If no private route is available, request one without disclosing the incident. Maintainers must not retaliate against good-faith reports.

These expectations apply in repository issues, pull requests and other spaces representing this project. This original policy is included under the repository's documentation license.
